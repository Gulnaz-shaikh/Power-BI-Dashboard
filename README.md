Business Sales Insights Dashboard

Overview

This project is a Power BI dashboard developed as a hands-on learning project by following a guided tutorial. 
It focuses on analyzing business sales performance through interactive visualizations and key performance indicators (KPIs).
The project helped strengthen my understanding of Power BI dashboard design, data modeling, and business reporting.

Objectives

Analyze overall sales performance.
Monitor profit and sales across different regions.
Compare product-wise sales and profit.
Understand customer purchasing patterns.
Practice creating interactive Power BI dashboards.

Dashboard Features

Total Sales KPI
Sales Gauge Chart
Product Category Analysis
Discount Analysis
Profit by Product
Sales by Region
Product-wise Sales, Profit, Quantity and Unit Price
Customer-wise Profit and Discount Analysis
Interactive Table for Detailed Records

Tools Used

Power BI Desktop
Power Query
DAX
Microsoft Excel

Skills Demonstrated

Data Cleaning
Data Transformation
Data Modeling
DAX Calculations
Dashboard Design
KPI Creation
Data Visualization
Business Reporting

Key Insights

Compares sales performance across different regions.
Identifies products contributing the highest sales and profit.
Analyzes discount percentages by product category.
Provides customer-level sales and profit analysis.
Presents business metrics through interactive visualizations.

Learning Outcome

This project was completed as part of my Power BI learning journey by following a guided tutorial.
It helped me develop practical experience in creating dashboards, working with different chart types, using DAX measures, 
and presenting business insights effectively.
